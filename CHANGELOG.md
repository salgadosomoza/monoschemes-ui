# Changelog

## 0.5.1 — 2026-11-26

- Fix the half-star rendering and keep RatingInput stable as its labels change.
- Add a Start here page, MonoSchemes branding, and sharing metadata to the public Storybook.
- Add Docs for Principles, Inverse zone, Motion, and Listing card, with improved dark-theme contrast and monochrome related links.

## 0.5.0 — 2026-11-25

- Make Gallery fill its container, with a 376 px side column in Featured and equal-width Grid columns.
- Add an optional location block to the Detail recipe and expand Map usage guidance.
- Support native downloads in Link through the `download` attribute.
- Soften decorative borders in Light, Dark, and inverse zones while retaining strong control borders and visible focus.
- Align text line heights to a 4 px grid.

## 0.4.0 — 2026-11-23

- Add agent conversation primitives: AgentMark, AgentStatus, Message, MessageActions, ToolCall, ApprovalRequest, Suggestions, Composer, and AgentThread.
- Add eight Tabler 3.52 icons for voice, tools, message actions, and stopping generation.
- Add keyboard, focus, disclosure, approval, and live status behavior with consumer-provided voice callbacks.
- Add agent conversation recipes and update the agent package guidance.

## 0.3.0 — 2026-11-23

- Add FormCombobox, a searchable single-select field with async loading, accessible listbox navigation, and accent-insensitive matching.
- Add JetBrains Mono caption/body scales and apply mono/body 2 to Kbd and CodeBlock.
- Add CardImage and the listing-card recipe, plus discoverability guidance and six Tabler icons for property listings.
- Add Gallery and GalleryViewer with featured/grid/mobile layouts, keyboard-accessible fullscreen browsing, thumbnails, and agent guidance.
- Fix the page-number spacing token used by Pagination on narrow screens.
- Add provider-independent Map/MapMarker and read-only/interactive Rating components, plus the Tabler star-filled icon.

## 0.2.0 — 2026-11-22

- Add the CommandPalette, Drawer, redesigned Table, TagGroup, DescriptionList, Tooltip, and typed Toast patterns.
- Add the Vite prototype starter template for agent-assisted product work; it uses DescriptionList and the published 0.2.x package.
- Keep EmptyState title and description centered, with a regression test.
- Include component contracts, usage guidance, stories, and tests for the new patterns.

## 0.1.1

- Fix InlineNotification error treatment and align the published CSS and component guidance.
