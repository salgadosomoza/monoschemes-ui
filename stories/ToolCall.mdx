# Tool call

A collapsible step that shows what the agent did with a tool. People can trust the answer because they can open each step and see its input and result.

</header>

<section>

## When to use

One Tool call per call, in order, inside the agent message. Collapsed by default once done; open it automatically only on error. Summaries in plain words («Read 3 files»), not function names alone.

</section>

<section>

## Example

<Canvas of={Stories.Done} />

</section>

<section>

## Guidelines

running: Agent/Mark thinking and the tool name. done: a one-line result. error: the message in text/error and, when it helps, a retry action. `defaultExpanded={true}` shows the input in Code block and the full result below.

</section>

<section>

## Accessibility

A disclosure: the header is a button with aria-expanded and aria-controls. Status changes are reported by Agent/Status, not by each Tool call.

</section>
