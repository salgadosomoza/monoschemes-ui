# Suggestions

Suggested prompts that help people continue a conversation.

</header>

<section>

## When to use

Offer next prompts above the Composer after an answer.

</section>

<section>

## Example

<Canvas of={Stories.Default} />

</section>

<section>

## Guidelines

Three or four next prompts as Button secondary sm in a row that wraps. Selecting one sends it as the user message. They disappear when the person starts typing. Connect `onSelect` to the thread’s send handler.

</section>

<section>

## Accessibility

Suggestions are rendered as named buttons in a group. Use distinct labels that make sense when read out of context.

</section>
