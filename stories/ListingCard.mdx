# Listing card

A card for listings and search results that combines an image, status, key facts, price and one action.

</header>

<section>

## When to use

<div className="storybook-docs__columns">

<div>

**Use for:** property, rental, product or venue listings in a grid or a results list.

</div>
<div>

**Don't use for:** a single featured item (use Card/Feature); dense comparisons between many items (use Table).

</div>

</div>

</section>

<section>

## Example

Card/Image (4:3) → Tag subtle sm for status + Save button (tertiary, icon-only) → title (h6) → location (body 2, text-secondary) → up to three Stat items → price (subtitle 1) → Button.

<Canvas of={Stories.Default} />

</section>

<section>

## Guidelines

- Keep three key facts at most; move the rest to the detail page.
- The title is the link to the detail page; do not make the whole card a link if it contains other buttons.
- Use the same image ratio in a grid so rows align.

</section>

<section>

## Accessibility

The image needs alt text that describes the place. The save button changes its label ("Save home" / "Remove from saved homes") and uses aria-pressed. Use one heading per card.

</section>
