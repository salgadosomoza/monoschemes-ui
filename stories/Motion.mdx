# Motion

Motion confirms an action or a change of state. It is quick and restrained: no bounce and no scaling.

</header>

<section>

## When to use

<div className="storybook-docs__columns">

<div>

**Use for:** hover and press feedback; opening and closing overlays; expanding an Accordion or moving the Tabs indicator; Toast entry.

</div>
<div>

**Don't use for:** decorative loops; page transitions; delaying content the user is waiting for.

</div>

</div>

</section>

<section>

## Example

<Canvas of={Stories.Motion} />

</section>

<section>

## Guidelines

- Use the duration tokens; never hard-code milliseconds.
- Arrivals use ease-out; exits use ease-in and can be shorter than the entry.
- Movement distance is distance-sm or distance-md, only for overlays and Toast.
- Animate color, opacity and position; do not animate size or rounded shapes.

</section>

<section>

## Accessibility

With prefers-reduced-motion, positional travel and the Accordion height animation are removed; color changes stay. Never convey information only through motion.

</section>
