# Message

One turn of the conversation. The thread reads like a document: every message is left aligned in a 720 px column, without coloured bubbles.

</header>

<section>

## When to use

Use an agent or user message for each turn. Use the system role for short thread events.

</section>

<section>

## Example

<Canvas of={Stories.Conversation} />

</section>

<section>

## Guidelines

agent: Agent/Mark sm, name and time, then the content slot (body 1 text, Code block, Table, Tool call, Approval request…). user: «You» and the content on bg/surface. system: a caption note between lines, for things like «Conversation renamed».

Message/Actions with Button tertiary sm iconOnly. agent: copy, retry, good and bad answer. user: edit and copy. On desktop they appear on hover or focus; on touch they are always visible. Each button has a Tooltip.

</section>

<section>

## Accessibility

The thread is role="log". Agent and user messages are articles with the author in the header. Action buttons have accessible names, not only icons. Long answers keep heading levels for screen reader navigation.

</section>
